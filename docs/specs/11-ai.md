# 11 — AI

**Status:** Draft — awaiting review

## 1. Who the AI controls

- **Teammates** of human players (positioning, making runs, supporting the ball carrier).
- **All opponents** in 1P vs CPU.
- **Both goalkeepers**, always.

## 2. Difficulty levels

Three levels. Team star ratings (see [12](12-modes.md)) add on top of these.

|                         | Easy     | Normal                 | Hard        |
| ----------------------- | -------- | ---------------------- | ----------- |
| CPU reaction time       | Slow     | Medium                 | Fast        |
| CPU passing accuracy    | Low      | Medium                 | High        |
| CPU pressing / tackling | Rare     | Regular                | Aggressive  |
| Keeper quality          | Beatable | Solid                  | Sharp       |
| Offside rule            | Off      | On                     | On          |
| Assists on by default   | All      | Auto-switch, pass-lead | Auto-switch |

All values are tuning-panel parameters.

Difficulty is the **CPU team's**: your own teammates and keeper always play at Normal, so Easy never gives you a
worse keeper. The tuning panel's "Computer team" sliders tune the opponent.

## 3. Assists (toggle at any level)

| Assist      | What it does                                                        |
| ----------- | ------------------------------------------------------------------- |
| Auto-switch | Control jumps to the best-placed player when defending or receiving |
| Aim help    | Shots bend towards the open part of the goal                        |
| Pass-lead   | Passes are aimed ahead of a running teammate                        |
| Auto-sprint | Sprints automatically on open ground                                |

## 4. Behaviour principles

- **Shape:** each team keeps a 4-4-2 shape that shifts with the ball; players return to position
  when not involved.
- **Attacking:** support the ball carrier with short options and forward runs; cross from wide areas;
  shoot when there's a clear chance.
- **Defending:** the nearest player presses the ball; others mark passing lanes; the back line holds
  an offside line (when offside is on).
- **Fair play:** the CPU never cheats — no speed boosts, no reading the player's input before it happens.
  Difficulty only changes reaction time, accuracy and decision quality.
- **Readable:** CPU players telegraph tackles and shots briefly, so humans can react.

## 5. Implementation constraints

- AI lives in `src/sim/` and produces the same _intents_ as human input (move + buttons), so the
  simulation treats human and AI players identically.
- Deterministic: AI uses the seeded RNG only, so replays and online v2 stay in sync.
- Cheap: the AI for 22 players fits in ≤ 2 ms per tick on a mid-range phone.
